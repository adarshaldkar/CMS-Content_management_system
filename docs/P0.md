## 1. Locked Visual Identity & Design Philosophy

> **"A typography-first, editorial publishing platform with a warm neutral public experience and a denser operational admin interface. Newsreader is used for editorial headlines; Plus Jakarta Sans for body/UI; JetBrains Mono selectively for metadata. Public pages prioritize content, readability, navigation and hierarchy. User pages prioritize writing, content management and community. Admin pages prioritize governance, review, moderation and system operations. The interface avoids generic AI-SaaS patterns, excessive cards, glassmorphism, gradients, decorative effects and repetitive layouts."**

### Core Typography & Token Architecture
* **Headlines & Editorial Titles**: *Newsreader* (Serif) — journalistic weight, optical sizing, elegant line flow.
* **Body Text & UI Elements**: *Plus Jakarta Sans* / *Inter* (Sans-serif) — crisp, high legibility, clean letter spacing.
* **Metadata & Numerical Data**: *JetBrains Mono* (Monospace) — used selectively for timestamps, word counts, version numbers (`v4`), and correlation IDs (`ERR-YYYYMMDD-XXXXXX`).
* **Color System (`docs/DESIGN-SYSTEM.md`)**: Restrained neutral professional palette. Warm paper whites (`#FAFAFA` / `#F8F9FA`), deep charcoal ink (`#111827`), subtle borders (`#E5E7EB`), and deliberate editorial accent tokens.
* **Semantic Skeleton Loaders**: Structural loading shapes (headline rules, image bounding boxes, author pill skeletons) matching actual editorial layouts instead of repetitive generic rectangular cards.

## 3. Comprehensive JIT Database Continuity (Pull-on-Miss)

### Overarching Invariant:
> **"A user should never discover a missing record or broken relationship just because the active DB changed."**

```text
                             ON-DEMAND JIT REPLICATION FLOW
                                           │
                                           ▼
                                 Active Database Query
                                           │
                         ┌─────────────────┴─────────────────┐
                         ▼                                   ▼
                   Record Found?                       Record Missing?
                         │                                   │
                   Return Data                               ▼
                                                    Fallback Database Lookup
                                                             │
                                                             ▼
                                                    Copy Record + Dependencies
                                                             │
                                                             ▼
                                                    Save to Active DB & Return
```

* **Zero Continuous Dual-Write Overhead**: Writes execute on `ACTIVE_DATABASE`.
* **Zero User Interruption**: Missing user, session, profile, article, revision, category, tag, comment, bookmark, or follow edge is pulled and replicated transparently on demand with valid Argon2id security hashes and relational integrity preserved.

## 4. Screen-by-Screen Functional Specifications

### A. Public Editorial Experience
1. **Homepage (`/`)**:
   - Asymmetrical Lead Story Hero with author avatar, reading time, and category pill.
   - Latest Stories Feed in horizontal editorial row layout.
   - Curated Category Sections (*Technology*, *Design*, *Security*).
   - Trending Sidebar with ranked numerical counters (`01`, `02`, `03`).
2. **Article Reader (`/articles/:slug`)**:
   - Comfortable reading width with responsive typography for optimal line length.
   - Live sticky reading progress bar.
   - Author metadata header + bio footer card.
   - Sanitized TipTap HTML: pull quotes, code blocks, zoomable figures with captions.
   - Interactive bar: Bookmark, Like/Reaction, Share, Repost, Comments drawer.
3. **Category & Tag Archives (`/category/:slug`, `/tags/:slug`)**:
   - Header with title, description, and total story count.
   - Paginated grid with sorting (`Latest`, `Most Read`).
4. **Author Public Profile (`/author/:id` or `/@:username`)**:
   - Author avatar, bio, follower count, published articles, and `Follow Author` button.
5. **Personalized "For You" Feed (`/feed`)**:
   - Stories dynamically curated based on user's selected topics and followed authors.
6. **Server-Side Search (`/search?q=...`)**:
   - 300ms debounced input, category/author filters, match snippet highlighting.

### B. Auth, Onboarding & User Workspace
1. **Auth Suite (`/login`, `/register`, `/forgot-password`, `/reset-password`)**:
   - React Hook Form + Zod validation, generic error messages, rate-limit 429 countdowns, Argon2id strength meters.
2. **Topic Onboarding (`/onboarding`)**:
   - Multi-select topic picker (e.g. *Technology*, *AI*, *Cybersecurity*, *Design*) to seed personalized feed.
3. **User Dashboard (`/dashboard`)**:
   - KPI metrics: Drafts, Submitted, Published, Total Reads.
   - Quick action bar: "New Story" $\to$ TipTap Editor.
4. **Stories Lifecycle Manager (`/stories`)**:
   - Filter tabs: `All` | `Drafts` | `Pending Review` | `Approved` | `Published` | `Scheduled` | `Rejected` | `Archived`.
   - Data table with state machine color badges, revision counters (`v4`), word counts, and history inspection.
5. **TipTap Editorial Studio (`/editor`, `/editor/:id`)**:
   - Full WYSIWYG rich text editor with autosave, revision history snapshots, and status transition submit triggers.
6. **Library, History & Social Hub (`/library`, `/history`, `/notifications`, `/network`)**:
   - Saved bookmarks, recently read stories, active notification feeds, and followers/following lists.
7. **Profile & Settings (`/profile`, `/settings`)**:
   - Name, bio, avatar upload, password change, and active session manager.

### C. Admin Governance & Control Suite (`/admin/*`)
1. **Admin Overview (`/admin`)**:
   - Platform KPIs, pending review alerts, and system health.
2. **Editorial Review Queue (`/admin/review`)**:
   - Table of `PENDING_REVIEW` submissions.
   - Side-by-side revision comparison drawer.
   - Actions: **Approve** (publish), **Reject** (with mandatory feedback note), **Schedule** (future timestamp).
3. **User & Role Governance (`/admin/users`)**:
   - User table with role assignment (`SUPER_ADMIN`, `ADMIN`, `EDITOR`, `AUTHOR`, `USER`) and account deactivation toggles.
4. **Taxonomy Management (`/admin/categories`, `/admin/tags`)**:
   - Full CRUD with article dependency safety checks.
5. **Media Library (`/admin/media`)**:
   - Upload modal with binary magic number checks, asset grid, URL copy, and delete.
6. **Comments Moderation (`/admin/comments`)**:
   - Moderation queue for user comments with approval and spam removal.
7. **Audit Log Explorer (`/admin/audit`)**:
   - Filterable security event log with global correlation IDs (`ERR-YYYYMMDD-XXXXXX`).
8. **Live Database Switcher (`/admin/database`)**:
   - Mutex-protected switch between PostgreSQL and MongoDB Atlas with on-demand JIT continuity verification.

